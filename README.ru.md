StackSignal — локальный радар библиотек, моделей и исследований. Он сопоставляет находки
с потребностями и существующим стеком проекта, готовит задание для небольшого эксперимента
и сохраняет фактический результат вместе с решением.

**Потребность → кандидат → эксперимент → свидетельства → решение**

## Быстрый запуск

Нужен **Python 3.11+** с `venv` и `pip`. Клонируйте репозиторий или скачайте исходный код:

```text
git clone https://github.com/ZheleznovAG/stacksignal.git
cd stacksignal
python stacksignal.py run
```

Откройте **http://localhost:8000**. Если интерпретатор называется `python3`, используйте его.
Команда создаст `.venv`, установит ограниченные версии зависимостей и скопирует пример
`.env`, если этого файла ещё нет. Первая установка требует интернета; последующие запуски
используют готовую среду, пока файлы зависимостей не изменятся.

Один Python launcher поддерживает Windows, Linux и macOS. Активация окружения и сборка
frontend не требуются. Установка и диагностика описаны в [руководстве по эксплуатации](docs/OPERATIONS.md).

## От проекта к решению

Новая установка пустая. Интерфейс сейчас на русском языке.

1. **Добавьте проекты.** В **Проекты → Сканировать папку** проверьте предложенные профили
   и импортируйте нужные. Профиль также можно создать вручную.
2. **Сформулируйте потребность.** Укажите текущий стек, ограничения и критерий проверки.
   Например: извлекать текст из фиксированного набора образцов документов без облачного API.
3. **Найдите кандидатов.** Нажмите **Собрать**, затем изучите **Сегодня** и рабочее пространство
   проекта. Эвристические совпадения и AI-оценки показываются со своим происхождением.
4. **Проверьте инструмент.** В **Потребности** подготовьте проверку и передайте её Markdown-задание
   Claude или другому агенту в папке целевого проекта.
5. **Сохраните итог.** Запишите результат и свидетельства. Подтверждение потребности и принятие
   технологии — отдельные явные решения. Новые требования делают прежний результат устаревшим.

Сбор и сопоставление по словам работают без AI. AI по умолчанию выключен. Для него нужен
отдельно настроенный шлюз или [файловый процесс с агентом](docs/AGENT-WORKFLOWS.md).
Шлюз не входит в репозиторий; произвольный model API требует адаптера к его контракту.

## Возможности и текущие границы

- Сбор из GitHub, Hugging Face, arXiv, npm и PyPI; запросы проектов, наблюдение за релизами и зависимостями.
- Проверяемый импорт папок, стек и зависимости, технические модели проектов, потребности и предварительные задачи.
- Эвристики, полный AI-анализ и релевантность конкретному проекту с указанием происхождения оценки.
- Поиск и вопросы по каталогу, FTS и необязательный локальный семантический поиск.
- Решения по проектам, заметки, история и основания пересмотреть выбор.
- Сохранённые задания проверок, результаты со свидетельствами и контроль актуальности.
- Ежедневный сбор при работающем сервисе и необязательный Telegram-дайджест.

Проект находится на ранней стадии. Это **локальное приложение для одного пользователя**:
Python/FastAPI, SQLite/Alembic и JavaScript без отдельной сборки. Запускайте один процесс
на loopback; аутентификации нет. Отбор кандидатов для потребностей пока лексический,
а семантический поиск используется в чате. Агенты выполняют работу вне StackSignal;
задания и результаты передаются вручную.

Реализованное поведение, ограничения и следующая задача описаны в [STATUS.md](docs/STATUS.md).

## Настройки и личные данные

Настройки — в [.env.example](.env.example). База, ключи, пути проектов, пакеты агентов
и резервные копии относятся к личному состоянию. `STACKSIGNAL_PRIVATE_DIR` позволяет
хранить личные `.env` и `data/` вне checkout. Существующие данные переносятся отдельно
при остановленном сервисе.

```text
python stacksignal.py doctor
python stacksignal.py backup
```

Backup сохраняет согласованный снимок настроенной SQLite-базы; остальные личные файлы
нужно сохранить отдельно. Коллекторы обращаются к API источников, а выбранные данные
анализа получает настроенный шлюз или агент. Локальный семантический поиск загружает
модель при первом использовании; `EMBEDDINGS_ENABLED=0` отключает его.
Подробнее: [эксплуатация](docs/OPERATIONS.md), [безопасность](SECURITY.md).
Скриншоты и тестовые профили в репозитории вымышленные.
