# Документация StackSignal

[Главная страница](../README.ru.md) · [English overview](../README.md)

StackSignal помогает пройти путь от потребности проекта к проверенному решению о технологии.
Приложение работает локально; подробные руководства и документы разработки сейчас на русском.

## Быстрые команды

Из корня репозитория, Python 3.11+ (`python3`, если так называется установленный интерпретатор):

```text
python stacksignal.py run
python stacksignal.py doctor
python stacksignal.py backup
```

Первый запуск установит зависимости и создаст пустую базу. Интерфейс — **http://localhost:8000**.
Настройки и личное состояние описаны в [OPERATIONS.md](OPERATIONS.md); резервное копирование
только базы не заменяет сохранение остальных личных файлов.

## Как продолжать разработку

Прочитайте [AGENTS.md](../AGENTS.md), [STATUS.md](STATUS.md) и [ARCHITECTURE.md](ARCHITECTURE.md).
Сверьте `git status --short` и `git log -5 --oneline`: документ о состоянии описывает код,
а фактическая история показывает, что закоммичено. В исходном ZIP без `.git` состояние удалённой
ветки неизвестно.

Ближайшая продуктовая задача — улучшить отбор кандидатов для потребностей. Её ожидаемый
результат и текущие ограничения зафиксированы в [STATUS.md](STATUS.md#следующая-продуктовая-задача).
Подготовка задания для агента и реальное выполнение эксперимента остаются отдельными действиями.

## Где поддерживать информацию

- `MISSION.md` — назначение, пользователи и критерий полезного результата.
- `STATUS.md` — рабочие возможности, ограничения и следующий шаг; обновляется при смене контрольной точки.
- `ARCHITECTURE.md` — долговременная карта кода, данных и транзакций.
- `usage.md`, `OPERATIONS.md`, `AGENT-WORKFLOWS.md` — пользовательские, эксплуатационные и агентные процессы.
- `AUDIT.md` — датированные находки и фактически выполненные проверки. Подготовленный CI не считается пройденным запуском.
- `AGENTS.local.md`, если он есть, — частные сведения установки; этот файл игнорируется и не публикуется.

Главные README дают обзор и запуск на двух языках. Подробные процедуры хранятся здесь,
чтобы изменения настроек или поведения не требовали править несколько разных руководств.
