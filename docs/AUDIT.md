# Аудит проекта — 22 октября 2026

## Область и метод

Проверены структура приложения и HTTP-граница, конфигурация, локальный запуск,
хранение/миграции/backup, сканирование папок, происхождение AI-оценок, потребности и
эксперименты, служебные команды, CI, публичный экспорт и документация.
Предыдущая незакоммиченная реализация экспериментов сохранена.

Метод: чтение ключевых модулей и связанных тестов, поиск платформенных зависимостей и
устаревших ссылок, воспроизведение ошибок, изолированные проверки, проверка схемы и
целостности SQLite, анализ текущего diff на личные данные. Личное состояние и исходный
код до изменений сохранены отдельно. Живые AI-вызовы, сбор и Telegram не использовались
как замена изолированным тестам.

## Проверка

| Среда / проверка | Фактический результат |
| --- | --- |
| Windows, Python 3.14.7 | **725 backend-тестов прошли, 1 пропущен** из-за ограничений создания файловой ссылки на Windows |
| Linux amd64, Python 3.11.17, чистый Docker-контейнер | **726 backend-тестов прошли**; новая `.venv` в папке с пробелом в имени |
| Chromium, Windows | **30 браузерных тестов прошли** на отдельной базе/сервере |
| Первый запуск Linux | Пустой список проектов, успешные миграции и HTTP health; вызов из другой рабочей папки |
| Личное хранилище и backup Linux | Runtime создан вне checkout; диагностика актуальной схемы и согласованный снимок базы прошли |
| Рабочая установка Windows | Новый launcher и штатный автозапуск работают; SQLite integrity/FK/schema в норме; кешированная модель возвращает вектор из 384 чисел из личной папки |
| Сохранность личных данных | Содержимое девяти таблиц проектов, зависимостей, решений, потребностей, событий, моделей и опытов совпало с согласованной резервной копией до аудита |
| Зависимости | `pip check` прошёл на Windows и Linux; ограничения включают выявленную Linux-зависимость `uvloop` |
| Документы / публичный исходный код | 50 локальных ссылок проверены; автоматическая проверка текущих исходных файлов не нашла credential matches |
| macOS и удалённый CI | Матрица подготовлена; фактический macOS-прогон и запуск обновлённого workflow в GitHub в рамках этого аудита не выполнялись |

Чистый Linux-прогон выдал одно предупреждение Starlette о deprecated HTTPX-совместимом
тестовом клиенте. Проверки прошли; при обновлении тестового транспорта следует сверить
новый контракт и изоляцию HTTP-тестов. Это не ошибка работающего HTTP-клиента шлюза.

Команды воспроизведения:

```text
python stacksignal.py setup --dev
python stacksignal.py test
python stacksignal.py setup --browser
python stacksignal.py test --browser
python stacksignal.py exec -- -m pip check
python scripts/public_release.py --check
python stacksignal.py doctor
```

Кроссплатформенная проверка запускается на очищенном исходном коде без `.env`, личной
базы и пакетов агентов. Тесты используют отдельные базы и отключают внешнюю сеть.

## Подтверждённые ограничения и оставшаяся работа

| Область | Ограничение / точка продолжения |
| --- | --- |
| Рекомендации под потребности | Лексический shortlist с точными словами/фразами. Семантическое ранжирование чата здесь ещё не подключено; это ближайшая продуктовая задача. |
| Измерение качества | AI-fallback и редкие пользовательские решения не дают независимого эталона. Нужен отдельный набор задач/ожидаемых результатов. |
| Агентные задания | UI готовит задание и хранит результат; выполнение происходит во внешнем агенте. Постоянной общей очереди с отменой/восстановлением ещё нет. |
| Сбор после аварии | Завершённые этапы фиксируются, но блокировка процесса и старые `running`-записи не являются системой восстановления после hard kill. |
| Развёртывание | Один локальный процесс, без аутентификации. Несколько workers и публичный сетевой сервер выходят за текущую эксплуатационную модель. |
| Журналы | Общий launcher умеет перенаправить вывод; длительную ротацию задаёт менеджер ОС. |
| Зависимости | Версии ограничены и согласованность проверяется через `pip check`; это не равнозначно полному аудиту известных уязвимостей пакетов. |

Этот аудит не является формальной проверкой безопасности, нагрузочным испытанием или
доказательством отсутствия неизвестных секретов во всей старой истории/бинарных файлах.
Сканер публичного исходного кода и ручной обзор дополняют друг друга.

## Проверка перед коммитами — 22 октября 2026

Дополнительно проверены публикуемые файлы, точное содержимое Git index перед каждым
коммитом, вся достижимая история открытого репозитория и метаданные авторов.
Gitleaks 8.30.1 проверен по контрольной сумме официального release-архива и запущен
на истории, staged diff и отдельном снимке публичного исходного кода.

| Область | Результат |
| --- | --- |
| Секреты | Действующие значения из локальной конфигурации и окружения, типовые ключи, приватные ключи и credentials в URL не обнаружены в проверяемой поставке. Gitleaks также не выявил секретов после разбора единственного ложного срабатывания. |
| Личные данные | Не обнаружены реальные домашние пути, личные email/телефоны или частные описания проектов. Совпадения названий с общими словами вручную проверены; демонстрационное имя папки в тесте заменено нейтральным. |
| Изображение | `docs/screenshots/projects-demo.png` просмотрен вручную: демонстрационный профиль и синтетические оценки, без личной установки или аккаунта. |
| Авторство | Используется публичное имя GitHub и адрес `users.noreply.github.com`. |
| Исключённые данные | `.env`, `AGENTS.local.md`, runtime-базы, личные профили, отчёты агентов и резервные копии не входят в index. Подробные отчёты сканирования хранятся вне репозитория. |

Ложное срабатывание Gitleaks относится к публичному SHA-256 tokenizer в
`backend/app/embeddings.py`. `.gitleaks.toml` дополняет стандартные правила единственным
исключением по точному пути и точному значению. Контрольная проверка подтверждает:
синтетический ключ в том же файле обнаруживается, эта сумма в другом файле также
не исключается. Команды повторения находятся в `CONTRIBUTING.md`.

История открытого репозитория проверяется по всем достижимым refs. Архив прежней
частной разработки и игнорируемые личные данные не являются публичной поставкой;
проверка не утверждает отсутствие секретов в этих архивах или недостижимых объектах Git.
